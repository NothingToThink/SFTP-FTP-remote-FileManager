# VolcanoBoys.Chat

Плагин добавляет команду `volcanoboys.chat.open` — «Открыть чат с ИИ-агентом».
Она открывает постоянную панель чата в главном окне. Сообщения и ответы остаются на панели
до завершения чата; история беседы передаётся модели на каждом ходе.

## Возможности и ограничения

- Агент отвечает на вопросы и может задавать уточняющие вопросы.
- При запуске доступны текущая папка и выбранные файлы: до 5 файлов размером не более 16 КБ каждый,
  только корректный UTF-8. Содержимое файлов считывается при первом сообщении и отправляется модели.
- Enter отправляет сообщение, Shift+Enter вставляет новую строку.
- По запросу агент может показать список файлов и свойства, прочитать текстовый файл (до 16 КБ),
  создать папку или файл, заменить содержимое файла (до 16 КБ), переместить или скопировать объект,
  удалить файл или пустую папку. За один ответ выполняется не больше пяти действий.
- Перед чтением файла приложение отдельно спрашивает, можно ли отправить его содержимое модели.
  Перед записью показывается полное новое содержимое; затем Backend ещё раз спрашивает разрешение
  на изменение. Отмена любого подтверждения оставляет соответствующее действие невыполненным.
- История ограничена 12 сообщениями пользователя; каждый ввод — не больше 4000 символов.
- Панель закрывается кнопкой «×». Закрытие отменяет текущий запрос и завершает команду плагина.
- Удаление папок с содержимым не поддерживается. Не отправляйте модели пароли, ключи или другие секреты.
- Сообщения и выбранные файлы отправляются внешнему провайдеру ИИ; в панели показывается предупреждение.

## Публичный API SDK

SDK предоставляет `IPluginContext.Chat` (`IChatService`). Плагин открывает `IChatSession` с заголовком
и приветствием, затем асинхронно получает сообщения пользователя, отправляет ответы и наблюдает
`ClosedToken` для отмены текущей работы, если пользователь закрыл панель.

Backend создаёт ограниченную чат-сессию, адресует сообщения текущему SignalR-клиенту и проверяет,
что ввод поступил от владельца этой сессии. Клиент показывает панель и отправляет сообщения в Backend.
Модальные окна `IWindow` продолжают работать отдельно.

## Настройки

| Переменная | По умолчанию | Назначение |
| --- | --- | --- |
| `FILEMANAGER_AGENT_API_KEY` | нет, обязательна | Ключ API; задаётся только в окружении Backend |
| `FILEMANAGER_AGENT_BASE_URL` | `https://api.timeweb.ai/v1` | Адрес OpenAI-совместимого API |
| `FILEMANAGER_AGENT_MODEL` | `yandex/yandexgpt-lite` | Имя модели |

## Публикация

```bash
dotnet publish plugins/VolcanoBoys.Chat -c Release -o <папка данных>/plugins/volcanoboys.chat
```

Папка данных — `$REMOTE_FILE_MANAGER_DATA_DIR/RemoteFileManager`, либо каталог данных пользователя
(на Linux `~/.config/RemoteFileManager`). В папке плагина должны находиться `plugin.json`,
`VolcanoBoys.Chat.dll` и опубликованные зависимости.
