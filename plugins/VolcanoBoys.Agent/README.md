# VolcanoBoys.Agent

Плагин «ИИ-агент» (`volcanoboys.agent`): команда `volcanoboys.agent.ask` — «Спросить ИИ-агента».
Пользователь выделяет файлы, задаёт вопрос, модель отвечает и может предложить правки и удаление файлов.
Каждое действие подтверждает пользователь в окне, которое показывает хост (Backend), а не плагин.
Плагин ссылается на `FileManager.Plugins.Sdk` и NuGet-пакет `OpenAI` (клиент OpenAI-совместимого API модели).

> **Внимание.** Содержимое выделенных файлов (до 5 файлов по 64 КБ) и текст вопроса уходят внешнему
> сервису модели по адресу из `FILEMANAGER_AGENT_BASE_URL`. Не выделяйте файлы с паролями, ключами и другими секретами.

## Что делает команда

1. Спрашивает «Что сделать с выделенными файлами?» (закрыли окно — команда завершается).
2. Читает выделенные файлы своего соединения: только текст в UTF-8, не больше 5 файлов и 64 КБ на файл.
   Папки, большие, бинарные и лишние файлы пропускаются, о чём модели сообщается в запросе.
   Без соединения или без выделения вопрос уходит без файлов.
3. Отправляет запрос модели (таймаут 90 с). Содержимое файлов в запросе помечено как данные, а не инструкции.
4. Текст ответа показывает окном (длинный обрезается до 4000 символов).
5. Правки модель присылает блоками `<<<FILE /полный/путь` … `>>>FILE` с новым содержимым файла целиком.
   Каждая правка — запись с перезаписью, подтверждение показывает хост.
6. Удаление — одна строка `<<<DELETE /полный/путь>>>`. Только файл или пустая папка (`DeleteAsync` с `recursive: false`):
   непустая папка даёт ошибку «папка не пуста», ничего не удаляется. Каждое удаление подтверждает пользователь
   в окне хоста («ИИ-агент хочет удалить файл … Разрешить?»).
7. Пути абсолютные, без `.`/`..` и `\`; корень `/` и пути с `/` на конце игнорируются. Не больше 5 действий
   (FILE и DELETE вместе) за ответ; один и тот же путь и в FILE, и в DELETE — оба блока игнорируются.
   Строка DELETE внутри блока FILE — содержимое файла, а не команда.
8. Порядок: сначала правки, потом удаления, каждое в порядке появления. Отклонённое или упавшее действие
   пропускается, остальные продолжаются. В конце — сводка: «Правки: применено N из M, отклонено K, ошибок E»
   и «Удаления: удалено N из M, отклонено K, ошибок E».

Модели в системном промпте прямо сказано, что она умеет только эти два действия, и запрещено задавать
уточняющие вопросы и просить подтверждения: подтверждение спрашивает приложение, а диалога с моделью нет.
Переименовать, переместить, создать папку, выполнить команду и удалить папку с содержимым она не может
и должна ответить об этом одной фразой.

Не делает: вызов функций и инструментов, историю диалога, стриминг, перемещение и переименование файлов,
создание папок, рекурсивное удаление.

Пример ответа модели и как он выполняется:

```text
Исправил опечатку и убрал старый черновик.
<<<FILE /home/user/notes.txt
Исправленный текст
>>>FILE
<<<DELETE /home/user/notes.old>>>
```

Покажется текст «Исправил опечатку и убрал старый черновик.»; затем хост спросит про перезапись `notes.txt`,
потом про удаление `notes.old`; в конце придёт сводка «Правки: применено 1 из 1, отклонено 0, ошибок 0.»
и «Удаления: удалено 1 из 1, отклонено 0, ошибок 0.».

## Настройки (переменные окружения Backend)

| Переменная | По умолчанию | Назначение |
| --- | --- | --- |
| `FILEMANAGER_AGENT_API_KEY` | нет, обязательна | ключ API; без него команда показывает ошибку |
| `FILEMANAGER_AGENT_BASE_URL` | `https://api.timeweb.ai/v1` | адрес OpenAI-совместимого API |
| `FILEMANAGER_AGENT_MODEL` | `yandex/yandexgpt-lite` | имя модели |

Переменные читаются при каждом запуске команды, но Backend наследует их при старте процесса:
задайте их в окружении, из которого запускаете Backend, и перезапустите его. Ключ нельзя хранить в репозитории.

## Как опубликовать и подключить

```bash
dotnet publish plugins/VolcanoBoys.Agent -c Release -o <папка данных>/plugins/volcanoboys.agent
```

`<папка данных>` — `$REMOTE_FILE_MANAGER_DATA_DIR/RemoteFileManager`, а если переменная не задана, то
`RemoteFileManager` в каталоге данных пользователя (на Linux `~/.config/RemoteFileManager`).
В папке `plugins/volcanoboys.agent/` должны лежать `plugin.json`, `VolcanoBoys.Agent.dll` и `OpenAI.dll`
с остальными зависимостями. Подробнее о публикации — в `plugins/Sample.Echo/README.md`.

## Проверка руками

1. Опубликовать плагин (см. выше), задать ключ и запустить Backend:
   `FILEMANAGER_AGENT_API_KEY=<ключ> dotnet run --project Backend --urls http://127.0.0.1:5116`.
2. Запустить клиент H4 (или тестовый клиент SignalR с обработчиками `ShowInputBox` и `ShowMessage`)
   и подключиться к серверу, например к локальному соединению.
3. Выделить текстовый файл и вызвать «Спросить ИИ-агента» (или `POST /commands/volcanoboys.agent.ask/execute`
   с заголовком `X-UI-Session`). Ввести, например, «Исправь опечатки».
4. Придёт окно с ответом модели; если модель предложила правку, хост спросит «ИИ-агент хочет перезаписать файл …
   Разрешить?». После ответа придёт сводка.
5. Удаление: «удали файл X» → жёлтое окно хоста «ИИ-агент хочет удалить файл … Разрешить?». «Отклонить» → файл
   на месте, в сводке «отклонено 1». «Удали папку с файлами» → честный ответ модели или ошибка «папка не пуста»;
   ничего не удалено.
