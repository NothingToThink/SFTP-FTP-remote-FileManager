# Спека UI: SWINE к защите

Oct 12, 2026 · @Kirill

## Контекст и цель

Цель — за 2–4 недели сделать интерфейс, который на защите за 6–7 минут покажет четыре вещи: подключение и работу с файлами, защиту от подмены ключа сервера, плагины с палитрой команд и, если успеем, туннели. Главный зритель — жюри, поэтому отполирован должен быть демо-путь, а не каждый угол приложения.

| Решение | Значение |
| --- | --- |
| Зритель | Жюри на защите, только смотрит на экран, приложение руками не трогает |
| Срок | 2–4 недели, точная дата не известна |
| Кто делает UI | 1 человек + агенты |
| Раскладка | Список хостов слева + одна панель файлов, как у Termius |
| Свинка | На максимум: персонаж, анимации состояний, шутливые тексты |
| Тема | Светлая и тёмная, переключатель виден на демо |
| Язык | Только русский |
| Стенд | Реальный VPS |
| ОС и экран | Заранее не известны: Windows или Linux, проектор |
| Что режем первым | Туннели |

Одна панель вместо двух снимает проблему stateful API из анализа пробелов: на одном соединении не будет двух вкладок, которые сбивают друг другу рабочую папку.

## Принципы

Свинка — характер, а не обои: она живёт в состояниях (ожидание, успех, ошибка, пусто), а рабочие поверхности остаются нейтральными и читаются с последнего ряда.

1. **Персонаж в состояниях, данные нейтральны.** Таблица файлов, пути, размеры и отпечатки ключей — без розового и без шуток. Свинка появляется там, где пользователь ждёт или что-то пошло не так.
2. **У каждого экрана четыре состояния:** загрузка, пусто, ошибка, норма. Экран без продуманного пустого и ошибочного состояния считается недоделанным.
3. **Ни одного «Internal server error» на экране.** Каждая ошибка бэкенда переводится в «что случилось и что делать». Это требует маппинга исключений на бэкенде (B3 из анализа).
4. **Читаемость на проекторе.** Основной текст 15 px, минимум 13 px, контраст текста не ниже 4.5:1, строка таблицы 36 px.
5. **Клавиатура наравне с мышью.** Палитра команд, Enter, Backspace, F2, Del, Ctrl+A работают с первого дня.
6. **Движение по делу.** Переходы интерфейса 150–250 мс; зацикленная анимация свинки — только пока пользователь ждёт.
7. **Демо-путь отполирован целиком, остальное — достаточно.** Всё, чего нет в сценарии демо, может быть простым, но не сломанным.

## Сценарий демо

Демо идёт 6–7 минут, и вся спека подчинена этому пути: каждый шаг ниже должен работать с первой попытки.

| Время | Действие | Что делает свинка | Что жюри должно заметить |
| --- | --- | --- | --- |
| 0:00 | Запуск приложения одной кнопкой | Сплэш: свинка с тремя прорезями | Бэкенд стартует сам, без консоли |
| 0:20 | Двойной клик по профилю VPS в списке хостов | Хвостик крутится туда-обратно, затем туго закручивается | Состояние подключения понятно без текста |
| 0:50 | Навигация по папкам, хлебные крошки, Backspace | — | Быстрый отклик, клавиатура |
| 1:30 | Перетащить файл из проводника в панель | Монетка падает в прорезь, прогресс внизу | Drag & drop, панель передач |
| 2:10 | Скачать папку | Пробка выскакивает из брюха | Передача папок работает |
| 2:40 | Подключиться к профилю с подменённым ключом | Визг: тряска и диалог «Чужой запах!» | Безопасность: отпечатки ключей, отказ по умолчанию |
| 3:40 | Ctrl+Shift+P, команда «Установить плагин» | Свинка «принюхивается» к новому плагину | Палитра команд, подтверждение прав |
| 4:30 | Правый клик по файлу → «Посчитать SHA-256» (из плагина) | — | Команда плагина появилась в меню без перезапуска |
| 5:20 | Туннели: свинка находит открытые порты, проброс к БД | Запах-волны над пятачком | Автоподсказка портов, которой нет у Termius |
| 6:20 | Переключить тему | Свинка в тёмной теме | Обе темы целиком |

Шаг с туннелями режется первым: без него демо укладывается в 5 минут.

Для шага с подменой ключа нужен подготовленный профиль, у которого сохранён заведомо чужой отпечаток для того же VPS. Тогда визг воспроизводится каждый раз без перенастройки сервера.

## Раскладка и экраны

Главное окно состоит из пяти зон: заголовок с поиском и переключателем темы, список хостов слева, панель файлов, раскрывающаяся панель передач и строка состояния с хвостиком.

&#91;embedded content: главное окно · пять зон\]

**Список хостов.** Поиск сверху, затем профили. У каждого профиля иконка протокола (прорезь Local, FTP или SFTP), имя, `user@host` мелким текстом и индикатор состояния — маленький хвостик. Кнопка «+ Добавить сервер» внизу. Двойной клик или Enter подключает.

**Панель файлов.** Сверху хлебные крошки, кнопки «назад» и «вверх», обновить и тулбар: загрузить, скачать, новая папка, удалить. Колонки: имя с иконкой типа, размер, изменён, права (для SFTP). Мультивыбор, контекстное меню, drag & drop из ОС. Клавиши: Enter — открыть, Backspace — вверх, F2 — переименовать, Del — удалить, Ctrl+A — выделить всё.

**Панель передач.** Свёрнута в полоску «2 передачи · 45%», по клику раскрывается списком: файл, прогресс, скорость, отмена.

**Строка состояния.** Прорезь протокола, хост, время подключения и хвостик keep-alive, который медленно покачивается, пока соединение живо.

| --- | --- | --- |
| Главное окно | Пять зон выше | P0 |

| Редактор профиля | Выбор протокола тремя прорезями, поля адреса, логина, пароля или ключа, «Проверить подключение» | P0 |

| Ключ сервера: первое знакомство | Отпечаток SHA-256, «Доверять» / «Отмена» | P0 |
| Ключ сервера: подмена | «Чужой запах!», старый и новый отпечаток, «Не подключаться» по умолчанию | P0 |
| Панель передач | Список, прогресс, скорость, отмена | P0 |

## Свинка: состояния и анимации

У свинки десять состояний, каждое привязано к событию в приложении; анимация живёт в стилях Avalonia, а ViewModel только выставляет флаг состояния.

| Состояние | Что делает свинка | Где видно | Событие |
| --- | --- | --- | --- |
| Пусто | Пустая копилка дремлет | Центр панели файлов | Нет профилей или папка пуста |
| Подключается | Хвостик раскручивается и скручивается, цикл 0.9 с | Строка хоста, центр панели | Ждём ответ бэкенда на подключение |
| Подключено | Хвост туго закручен, один раз виляет | Строка хоста, строка состояния | Подключение успешно |
| Живое соединение | Хвост медленно покачивается раз в 8 с | Строка состояния | Keep-alive работает |
| Загрузка | Монетка падает в прорезь | Панель передач | Старт загрузки файла |
| Скачивание | Пробка выскакивает из брюха | Панель передач | Старт скачивания |
| Передача готова | Короткий прыжок | Панель передач | Все передачи завершены |
| Ошибка | Хвост висит прямо, уши опущены | Центр панели, строка хоста | Неверный пароль, нет сети, нет доступа |
| Подмена ключа | Визг: тряска 300 мс и линии тревоги | Диалог | `HostKeyMismatch` (409) |
| Туннели | Запах-волны над пятачком | Экран туннелей | Поиск открытых портов |

**Как сделано.** Хвостик — свой контрол `PigTail` со свойством `Curl` (спираль Эйлера постоянной длины, см. обсуждение анимации). Остальные анимации — трансформации и прозрачность SVG-частей через keyframe-анимации в стилях. Lottie не нужен.

**Иллюстрации.** Рисует Claude. Нужен полноценный персонаж в том же линейном стиле, что иконки: пять сцен — пустая копилка, подключение, ошибка, визг, успех. Каждая — SVG, разбитый на части (тело, хвост, уши, пятачок), чтобы анимировать части отдельно.

**Правила движения.** Переходы интерфейса 150–250 мс с замедлением в конце. Зацикленная анимация только во время ожидания. В таблице файлов ничего не анимируется. В настройках есть «Уменьшить анимацию», который оставляет только смену поз без движения.

## Визуальная система

**Шрифты.** Unbounded — заголовки и логотип. IBM Plex Sans — весь интерфейс. IBM Plex Mono — пути, размеры, права, отпечатки ключей. Все три с кириллицей. Шрифты встраиваются в приложение ресурсами: ОС демо-машины не известна, системным шрифтам доверять нельзя.

| Роль | Размер | Насыщенность |
| --- | --- | --- |
| Заголовок экрана | 28 px, Unbounded | 700 |
| Заголовок раздела | 20 px, Unbounded | 500 |
| Основной текст, строки таблицы | 15 px | 400 |
| Подписи, мелкий текст | 13 px | 400 |

**Сетка.** Шаг 4 и 8 px. Скругления 8 px у кнопок и полей, 12 px у карточек, 16 px у диалогов. Строка таблицы 36 px, кнопка тулбара 44×44 px с иконкой 20 px. Минимальный размер окна 1024×700.

**Иконки.** Фирменные — из набора со свинкой для функций приложения. Типы файлов — нейтральный линейный набор в той же толщине линии (например, Lucide), без свинок: в таблице их сотни, персонаж там утомит.

## Тексты и тон

Шутка живёт в заголовке, а суть — в тексте под ним: заголовок может хрюкнуть, но тело сообщения всегда говорит, что случилось и что делать.

- Обращение на «вы», глаголы действия на кнопках («Подключиться», а не «ОК»).
- Не шутить там, где можно потерять данные: удаление, перезапись, доверие новому ключу.
- Технические детали (код ошибки, стек) — под раскрывающимся «Подробнее», не в основном тексте.

| Ситуация | Заголовок | Текст | Кнопки |
| --- | --- | --- | --- |
| Нет профилей | Копилка пустая | Положите в неё первый сервер: SFTP, FTP или локальную папку. | Добавить сервер |
| Подключение | — | Подключаемся к prod-01… | Отмена |
| Неверный пароль | Хрю, не пускают | Сервер prod-01 не принял логин или пароль. Проверьте их в профиле. | Открыть профиль · Повторить |
| Нет сети | Связь пропала | Сервер не отвечает. Проверьте адрес и подключение к интернету. | Повторить |
| Первый ключ | Знакомимся с сервером | Свинка видит prod-01 впервые. Отпечаток ключа: `SHA256:…`. Сверьте его с администратором сервера. | Доверять · Отмена |
| Подмена ключа | Чужой запах! | Ключ prod-01 изменился с прошлого подключения. Так бывает после переустановки сервера, но так же выглядит перехват соединения. | Не подключаться · Доверять новому ключу |
| Загрузка готова | Положили в копилку | 3 файла, 12 МБ загружены в /var/www. | Показать |
| Скачивание готово | Достали, не разбивая | 12 МБ скачаны в Загрузки. | Открыть папку |
| Удаление | Удалить 3 файла с сервера? | Это нельзя отменить. | Удалить · Отмена |
| Установка плагина | Установить «Checksum»? | Плагин получит полный доступ к файлам и серверам. Ставьте плагины только из источников, которым доверяете. | Установить · Отмена |
| Палитра команд | — | Что сделать? Начните вводить команду | — |

В диалоге подмены ключа кнопка по умолчанию — «Не подключаться»: Enter не должен случайно принять чужой ключ.

## Приоритеты и урезание

P0 — это демо-путь без туннелей; если к концу второй недели P0 не проходит целиком, P1 и P2 не начинаются.

| Пункт | Приоритет | Зависит от бэкенда |
| --- | --- | --- |
| Токены темы, шрифты, обе темы, переключатель | P0 | — |
| Главное окно: хосты, панель файлов, строка состояния | P0 | B1: вернуть `dir/size`, `dir/copy`, `dir/move` (PR #44) |
| Подключение с хвостиком, ошибки подключения | P0 | B3: маппинг исключений в 401/403/404 |
| Пустые состояния, иллюстрации свинки | P0 | — |
| Загрузка и скачивание с панелью передач | P0 | Прогресс: минимум — по байтам на клиенте; файлы для демо до 20 МБ (лимит B6) |
| Диалоги ключа сервера: первое знакомство и подмена | P0 | S7: подтверждение нового ключа вместо молчаливого TOFU |
| Палитра команд со встроенными командами | P0 | `CommandRegistry` на клиенте |
| Запуск одной кнопкой | P0 | 0.7: `BundledServerLauncher` |
| Установка плагина и команда в меню | P1 | Плагины, фаза 1: `PluginManager`, контрибуции, `POST /commands/{id}/execute` |
| Страница плагинов | P1 | То же |
| Сплэш | P1 | — |
| «Уменьшить анимацию» | P2 | — |
| Туннели с подсказкой портов | P2 | Есть с #43/#46, нужна перерисовка |

Порядок урезания, если не успеваем: туннели → страница плагинов → установка плагина (остаётся заранее установленный плагин и его команда в меню) → сплэш. Режется целым шагом демо, а не качеством оставшихся.

## Риски демо

Главный риск — сеть в аудитории: демо идёт на реальном VPS, и без запасного пути одна потеря Wi-Fi обнуляет всё.

| Риск | Чем грозит | Подстраховка |
| --- | --- | --- |
| Нет сети или VPS не отвечает | Демо останавливается на первом шаге | Раздача интернета с телефона; запись полного прогона на видео; по возможности Docker с OpenSSH на ноутбуке как запасной профиль |
| Неизвестная ОС и проектор | Другие шрифты, мелкий текст, обрезанное окно | Шрифты встроены; проверка на Windows и Linux, на 1280×720 и масштабе 150% |
| Бэкенд не поднялся | Пустое окно на старте | Запуск одной кнопкой с понятной ошибкой, если порт занят |
| Подмена ключа не воспроизводится | Пропадает самый сильный шаг про безопасность | Профиль с заранее сохранённым чужим отпечатком, проверен на генеральном прогоне |
